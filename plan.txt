# Benchpilot — Log view / webview unification plan

Goal: one authoritative slot table (gSlots) shared by the CYD display and the
webview. Counts become cumulative-since-boot (999-wrap), the 300-message RAM ring
is deleted, and memory becomes constant/bounded.

All line numbers refer to the current src/main.cpp (after the earlier drawLogView
alignment/hex fixes).

## Step 1 — Data model (struct + globals)
- Remove from `BoatData` (lines 287–289): `msgLog[300][128]`, `msgLogWriteIdx`,
  `msgLogCount`. Frees 38.4 KB static RAM.
- Slot struct (line 349): drop unused `seen` field
  -> `{ char key[64]; int count; char text[MSG_TEXT_LEN]; }`.
- Hoist `gNewestSlot` from function-static (line 1195) to file scope (near 350):
  `static int gNewestSlot = -1;`.
- Add file-scope `static uint32_t gSlotsSeq = 0;` (generation counter) and
  `static int gLogLastSeq = -1;` (renames gLogLastWriteIdx, line 340) — both
  declared ABOVE `BoatData` so `pushMsg` can see them.
- Forward-declare `static void slotPush(const char *text);` above `BoatData`.

## Step 2 — pushMsg becomes the single writer (BoatData::pushMsg, lines 295–300)
Replace body with:
    slotPush(text);     // update/insert slot, count++, newest text, gNewestSlot
    gSlotsSeq++;        // generation bump -> CYD tick + web update detection
Remove the ring indexing / msgLogCount lines.

## Step 3 — New slotPush() (define after msgKey, ~line 1155)
Uses existing msgKey (line 1141) + slot globals:
- compute key -> linear search gSlots[0..gSlotCount);
- hit: count++ (wrap >999 -> 1), copy newest text, gNewestSlot = found;
- miss && gSlotCount < MAX_SLOTS: append {key, count=1, text}, gNewestSlot=idx,
  gSlotCount++;
- over MAX_SLOTS: drop (unchanged behavior).

## Step 4 — drawLogView() (lines 1170+)
- Delete the slot-rebuild ring walk (1190–1225), newestIdx/total/curKey/
  firstEncounter locals, and the anyActive block (1227–1234); replace with
    if (gSlotCount == 0) { fillRect(0,0,320,STATUS_BAND.y,TFT_BLACK); return; }
- active (1237–1238): simplify to `int active = gSlotCount;` (scroll/maxScroll
  math unchanged).
- Tick/redraw guard (1246–1248): replace `g.msgLogWriteIdx == gLogLastWriteIdx`
  with `gSlotsSeq == gLogLastSeq` (playTick / update accordingly).
- Everything else (rendering, columns, wrap logic, fitWidth) untouched.

## Step 5 — /status (handleStatus, lines 2321–2331)
Replace the raw "msgs":[...] array with "slots":[...] in gSlots order:
    {"c":count, "l":true/false, "t":"<text>"}     // "l"=1 on gNewestSlot
Active slots only (count>0). Bounded by MAX_SLOTS=50 (~3–4 KB), so
json.reserve(8192) suffices — no heap-growth/truncation risk.

## Step 6 — Web JS
- Line 2036: drop `gSlots=new Map()` and `_newestKey`; add `_prevLatest=''`.
- Render block (2129–2153): replace client-side dedup/seen/Map with direct render:
      let h='', lt='';
      if(d.slots) for(let sp of d.slots){
        h += logLine(sp.t, sp.c, sp.l);          // existing logLine() unchanged
        if(sp.l) lt = sp.t;
      }
      if(lt && lt!==_prevLatest){ _prevLatest=lt; beep(); }   // newest tick
- Keep pause/scroll/copy logic (2154–2157) and logLine() (2159).

## Step 7 — cleanup
- MSG_LOG_SIZE (line 24) becomes unused -> remove the define (optional).
- Update `gLogLastWriteIdx = -1` reset on entering log view (line 2702) to
  `gLogLastSeq = -1` (fresh tick on first new message after entering).

## Verify
- `pio run` build must pass clean.

## Behavior / memory result
                Before                          After
  Counters     CYD max 300, web max 200         both cumulative since boot,
                                                wrap 999 -> 1
  Web history  since page-load only             same as CYD (since boot, <=50 slots)
  RAM static   ring 38.4KB + slots ~10KB        slots only ~10KB ( -38.4KB )
  /status heap up to ~26KB                      ~3–4KB, bounded
  SD log       rotation at 90% full (kept)      unchanged

## Notes / caveats
- Counter wraps 999 -> 1, not to 0: count==0 is the renderer's "hidden slot"
  sentinel; wrapping to 0 would hide the row.
- New distinct keys beyond MAX_SLOTS=50 are dropped (same as today; old keys are
  never evicted, so CYD log view = since-boot history — by design).
- The RAM ring is gone; full raw history remains on the SD log + its rotation.
